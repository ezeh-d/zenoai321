
# REYES JARVIS All-Phases Edition

This source package combines the existing HUD, voice, vision, memory, desktop automation and agent code with a new core orchestration layer, task queue, model router, safety gate and plugin discovery.

## Install
1. Extract to `C:\Users\T21SERVICES\Desktop\REYES`.
2. Run `INSTALL_REYES.bat`.
3. Run `START_REYES.bat`.

## Wake phrases
`gee`, `gee how far`, `reyes`, `what's good`, `guy`, `blood`.

## New commands
- `what can you do`
- `list plugins`
- `plugin hello`
- `queue task open chrome then search for AI news`
- `list tasks`
- `which model for debug this Python code`

## Important
This is a capable desktop-assistant foundation, not unrestricted movie software. External services require their own accounts/API keys. OCR requires Tesseract. Playwright installs Chromium separately. Kokoro/Whisper models are downloaded during setup and are intentionally excluded from this small ZIP.
